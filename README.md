# RIMLINE — учебный лендинг магазина дисков

Статический адаптивный сайт на чистом HTML, CSS и небольшом JavaScript. Внешние библиотеки и удалённые изображения не используются.

## Направление и референсы

Выбрано направление **Fitment Lab**: графитовая техническая среда, бирюзовая маркировка параметров и крупное предметное изображение диска. Главный сценарий первого экрана — перейти к точному подбору по автомобилю, а не просто посмотреть на товар.

Референсы переданы пользователем; решения ниже зафиксированы по приложенным скриншотам, а не по живому просмотру сайтов:

- [KEPAQI Russia](https://kepaqi-russia.ru/?ref=https://tilda.cc/ru/madeontilda/) — подходит тёмный технический первый экран, крупный предметный визуал и ранний показ популярных товаров. Для RIMLINE вместо электроинструмента использована локальная векторная иллюстрация диска, а каталог дополнен фильтрами.
- [CRYSTACELL](https://crystacell.store/?ref=https://tilda.cc/ru/madeontilda/) — подходит спокойная редакционная сетка, крупная типографика и лаконичные подписи к продукции. Эти идеи использованы в светлом каталоге и блоке подбора; композиция страницы и карточки сделаны заново.

## Что реализовано

- Семантические секции HTML5, CSS Grid/Flexbox, адаптация для телефона и широкого экрана.
- Навигация по якорям с плавной прокруткой и поддержкой `prefers-reduced-motion`.
- Каталог из одиннадцати реальных вариантов LS и LS Forged; фильтр по типу конструкции и PCD, пустой результат объясняется пользователю.
- Модальное окно подбора на нативном `<dialog>`: клавиатурный фокус управляется браузером, закрытие — кнопкой, кликом по фону или Escape.
- Проверка обязательных полей и формата телефона; после проверки показывается локальное подтверждение. Серверной отправки и хранения данных нет.
- Векторные локальные иллюстрации дисков и запасной визуальный вариант при ошибке загрузки карточного изображения.
- Контактные сведения пользователя повторены в шапке, контактном блоке и подвале. На карточках указаны реальные параметры конкретного варианта и цена за один диск по ссылкам на продавца.
- Иллюстрации колёс стилизованные и не выдаются за фотографии точных моделей; у каждой карточки есть ссылка на исходную товарную страницу.

## Запуск и публикация

Откройте `index.html` в браузере — сборка и установка пакетов не нужны. Для GitHub Pages можно опубликовать содержимое этой папки как отдельный репозиторий или выбрать её как папку сайта в существующем репозитории.

Перед реальной публикацией перепроверьте цены и наличие. Форма сейчас ничего не отправляет; для приёма настоящих заявок потребуется серверный обработчик или подключённый сервис форм.
